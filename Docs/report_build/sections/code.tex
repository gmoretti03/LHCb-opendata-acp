\section{Code and Data Availability}
\label{sec:code}
\emph{In short: Python code with the package versions listed here; frequentist, Bayesian and machine-learning code and notebooks are in the accompanying repository.}
All code is written in Python $\geq$3.12, with \texttt{scikit-learn}~\cite{sklearn} for the classical machine-learning models and \texttt{TensorFlow}/\texttt{Keras}~\cite{tensorflow} for the neural networks. Key package versions: \texttt{uproot 5.7}, \texttt{iminuit 2.32.0}, \texttt{emcee 3.1.6}, \texttt{corner 2.3.0}, \texttt{scikit-learn 1.9}, \texttt{tensorflow 2.21.0}, \texttt{keras 3.15.1}, \texttt{scipy 1.18}, \texttt{numpy 2.4}, \texttt{pandas 3.0}.

The dataset is the CERN Open Data record \href{https://opendata.cern.ch/record/4900}{4900} ("Matter Antimatter Differences -- B meson decays to three hadrons"). The analysis code is available in the accompanying repository, in \texttt{Code\_general/Analysis/Frequentist/} (frequentist fits, the common systematic study, and \texttt{freq\_validation.py} with the toy-MC experiments, profile likelihoods, confidence belt and bootstrap studies of Sec.~\ref{sec:validation} and Appendix~\ref{sec:appendix_checks}), \texttt{Code\_general/Analysis/Bayesian/} (notebooks \texttt{01\_bayes\_mass\_fit\_and\_asymmetry}: nominal fit, Bayes factors, systematic study, toy-MC closure test, magnet polarities and Dalitz plane; \texttt{02\_bayes\_model\_checks\_and\_priors}: posterior predictive checks, convergence diagnostics, sensitivity to the priors and comparison with the profile likelihood; \texttt{03\_bayes\_vs\_frequentist\_low\_statistics}: the two approaches at low statistics; the mass model, the sampler and the toy generator are in \texttt{bayes\_model.py}), and \texttt{Code\_general/Analysis/Machine\_Learning/} (notebooks \texttt{04\_ml\_signal\_background\_classifiers}: weak labels, classifiers, calibration, uncertainty and hyperparameters; \texttt{05\_ml\_selection\_and\_local\_asymmetry}: effect of the selection on $\Araw$, K-means and null tests on the Dalitz plane, comparison with the published analysis; helper functions in \texttt{ml\_tools.py}). Each of these notebooks opens with a table of the sections and figures of this paper that it produces and generates those figures from its saved results, so that they can be rebuilt without repeating the long computations; the common style is in \texttt{Code\_general/Analysis/plot\_style.py}. The figures of the frequentist analysis are produced from its saved results by \texttt{regen\_figures\_validation.py}, \texttt{regen\_figures\_systematics.py} and \texttt{regen\_figures\_extras.py} in the figures directory of the report. All random numbers are generated with fixed seeds, so the toy-MC experiments can be reproduced.
