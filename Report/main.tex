\section{Limitations and Future Work}
\label{sec:limitations}
\todo{Shared. This section can be drafted almost entirely NOW by condensing the already-written "Limiti noti" lists -- don't re-derive, translate/tighten what's already there:
\begin{itemize}
    \item From \texttt{bayes}: background assumed symmetric between charges (not validated independently of the magnet cross-check); Savage-Dickey Bayes factor's exact value is bandwidth-fragile (only the qualitative conclusion is robust); toy-MC coverage used a limited number of replicas and showed a mild (${\sim}1.3\sigma$) hint of undercoverage, not fully resolved; even the best signal model (Crystal Ball, floated shape) gives $\chi^2$/ndof$\,{\approx}\,2$, not $\approx 1$; Dalitz local-asymmetry binning is coarse.
    \item From \texttt{mach\_lear}: severe class imbalance in the weak labels (1217 background-like vs 15119 signal-like); MC Dropout and RF ensemble-variance uncertainty estimates disagree by ${\sim}18\times$ in absolute scale (only weakly correlated per-event, $\rho\approx0.24$); hyperparameter/architecture search used a non-exhaustive grid; the $\Araw$-vs-threshold check is simple post-cut counting, not a full mass refit on the ML-selected sample.
    \item Cross-cutting: the mass window, background model, and signal-region definition were chosen from the Bayesian fit alone and still need to be reconciled with Marco's frequentist choices; no detector-level systematic (efficiency, production asymmetry) correction is applied anywhere -- $\Araw$ is explicitly NOT $\ACP$.
\end{itemize}
Future work: sWeight-based (not simple-cut) local Dalitz asymmetry; full mass refit after ML selection instead of counting; extend the toy-MC coverage study with more replicas.}

\section{Code and Data Availability}
\label{sec:code}
All code is written in Python $\geq$3.12, run in a dedicated \texttt{conda} environment (\texttt{cern}). Key package versions: \texttt{uproot 5.7}, \texttt{iminuit 2.32} \todo{Marco confirm}, \texttt{emcee 3.1.6}, \texttt{corner 2.3.0}, \texttt{scikit-learn 1.9}, \texttt{tensorflow 2.21.0}, \texttt{keras 3.15.1}, \texttt{scipy 1.18}, \texttt{numpy 2.4}, \texttt{pandas 3.0}.

The dataset is the CERN Open Data record \href{https://opendata.cern.ch/record/4900}{4900} ("Matter Antimatter Differences -- B meson decays to three hadrons"). Analysis code is organized per branch in the project git repository: \texttt{Code\_general/Frequentist/}, \texttt{Code\_general/Bayesian/}, \texttt{Code\_general/Machine\_Learning/}.
